# 3. Git

## Установка и настройка

- **Установка Git:**

```bash
sudo apt update && sudo apt install git
```

- **Проверка версии:**

```bash
git --version
```

- **Указать имя пользователя (глобально):**

```bash
git config --global user.name "Your Name"
```

- **Указать email (глобально):**

```bash
git config --global user.email "you@example.com"
```

- **Задать имя главной ветки по умолчанию:**

```bash
git config --global init.defaultBranch main
```

- **Посмотреть все настройки:**

```bash
git config --list
```

## Создание и получение репозитория

- **Инициализация нового репозитория в текущей папке:**

```bash
git init
```

- **Клонирование удалённого репозитория:**

```bash
git clone https://github.com/user/repo.git
```

- **Клонирование в папку с другим именем:**

```bash
git clone https://github.com/user/repo.git my-folder
```

## Базовый цикл работы

- **Статус репозитория (что изменено, что в индексе):**

```bash
git status
```

- **Добавить конкретный файл в индекс:**

```bash
git add file.txt
```

- **Добавить все изменения в индекс:**

```bash
git add .
```

- **Создать коммит:**

```bash
git commit -m "Описание изменений"
```

- **Добавить в индекс изменённые файлы и сразу закоммитить (только для уже отслеживаемых):**

```bash
git commit -am "Описание изменений"
```

- **Изменить последний коммит (сообщение или состав файлов):**

```bash
git commit --amend
```

## Просмотр истории и изменений

- **История коммитов:**

```bash
git log
```

- **Компактная история с графом веток:**

```bash
git log --oneline --graph --all
```

- **Показать изменения в рабочей папке (ещё не в индексе):**

```bash
git diff
```

- **Показать изменения в индексе (после git add):**

```bash
git diff --staged
```

- **Показать содержимое конкретного коммита:**

```bash
git show <commit-hash>
```

## Ветки

- **Список веток:**

```bash
git branch
```

- **Создать новую ветку:**

```bash
git branch feature-name
```

- **Переключиться на ветку:**

```bash
git switch feature-name
```

- **Создать ветку и сразу переключиться на неё:**

```bash
git switch -c feature-name
```

- **Слить ветку в текущую:**

```bash
git merge feature-name
```

- **Удалить ветку (после слияния):**

```bash
git branch -d feature-name
```

- **Принудительно удалить ветку (с неслитыми изменениями):**

```bash
git branch -D feature-name
```

## Удалённые репозитории

- **Показать подключённые удалённые репозитории:**

```bash
git remote -v
```

- **Добавить удалённый репозиторий:**

```bash
git remote add origin https://github.com/user/repo.git
```

- **Отправить изменения в удалённый репозиторий:**

```bash
git push origin main
```

- **Отправить ветку и запомнить связь (дальше хватит просто git push):**

```bash
git push -u origin main
```

- **Скачать изменения без слияния:**

```bash
git fetch
```

- **Скачать и сразу слить изменения:**

```bash
git pull
```

## Отмена изменений

- **Убрать файл из индекса (изменения в файле сохраняются):**

```bash
git restore --staged file.txt
```

- **Отменить изменения в файле (вернуть к последнему коммиту):**

```bash
git restore file.txt
```

- **Откатить последний коммит, сохранив изменения в рабочей папке:**

```bash
git reset --soft HEAD~1
```

- **Откатить последний коммит и удалить все изменения (необратимо):**

```bash
git reset --hard HEAD~1
```

- **Создать коммит, отменяющий указанный (безопасно для опубликованной истории):**

```bash
git revert <commit-hash>
```

## Временное сохранение изменений (stash)

- **Спрятать текущие изменения:**

```bash
git stash
```

- **Посмотреть список спрятанных изменений:**

```bash
git stash list
```

- **Вернуть последние спрятанные изменения и удалить их из списка:**

```bash
git stash pop
```

## Игнорирование файлов

- **Создать файл игнорирования в корне проекта:**

```bash
touch .gitignore
```

- **Пример содержимого `.gitignore` для Node.js/React-проекта:**

```
node_modules/
dist/
.env
*.log
```

## Теги

- **Создать тег на текущем коммите:**

```bash
git tag v1.0.0
```

- **Отправить теги в удалённый репозиторий:**

```bash
git push --tags
```

## Пути к ключевым файлам

- Глобальная конфигурация пользователя: `~/.gitconfig`
- Конфигурация конкретного репозитория: `.git/config`
- Служебная папка репозитория: `.git/`
- Файл игнорирования: `.gitignore` (в корне проекта)
